# MAC-Address-Table-Project

A MAC-address is assigned to the Network Interface Card (NIC). It is a 48-bit address, and it is permanent. It is at a layer 2, data link layer, in the OSI Model.

# Lab Requirements

This repository provides a full configuration solution for the following tasks:
1. Set up physical cable and connections.
2. Configure PC's and switch.
3. Allocating IP address to individual PCs.
4. Locating MAC address on individual PCs pertaining to their MAC address.

# MAC-Address Location

The MAC-Address is located on the Ethernet adapter. Another way to find the MAC-Address is to head to command prompt and type in ipconfig /all.

# Data Analysis

The MAC-Address from the Ethernet adapter matches along with the switch. In addition, the MAC-Address on the Ethernet adapter corresponded to each individual computers with their IP address.
